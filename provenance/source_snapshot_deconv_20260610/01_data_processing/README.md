# 01 — Data processing / 数据处理

Prepares the inputs the rest of the pipeline consumes. Source `../paths.env` first.

## Shared preprocessing recipe (identical across datasets)
This recipe is applied **inside** the Stage-1 training scripts (`../02_training/`) when they
load the reference single cell — it is documented here because it defines the gene sets that
inference depends on:

1. raw counts → `sc.pp.normalize_total(target_sum=1e4)` (CP10K)
2. `sc.pp.log1p`
3. `sc.pp.highly_variable_genes(n_top_genes=3000)` → **core / encoder-input genes**
   (`input_size = len(core_genes)`)
4. shared **reference ∩ bulk** gene panel → **decoder-output genes** (`output_size`; HCA = 25,366)
5. query bulk: same normalize → log1p, reindexed to the shared panel
6. train/test split 80/20 (HCA adds 5-fold CV; **fold 2** is the reported fold)
